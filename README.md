# CP-090 TuneRecap: Music Listening Analytics and Year-in-Review Generator

## Team
Satendra Chauhan, Java Track

## How to run
javac Main.java
java Main

## Features that work
1. Load and add listening log entries with input validation (song, artist, genre, date, hour, minutes)
2. Show the Top 5 songs, artists, and genres by listening minutes
3. Show total listening time and the busiest month
4. Show listening by hour of day (00:00 to 23:00) as a text bar chart
5. Find the longest listening streak in consecutive days
6. Stretch 1: Compare two users and show a taste-match percentage
7. Stretch 2: Export the Year-in-Review summary as a shareable text card (TuneRecap_Card.txt)
